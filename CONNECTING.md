# Connect ContextForge to Claude or Codex

Self-hosted mode needs only the Streamable HTTP URL:
`http://localhost:7860/gradio_api/mcp/`.

Hosted mode also requires this HTTP header:

```text
Authorization: Bearer cf_live_<key-id>_<secret>
```

Use the configuration generated by Gradio under **Use via API → MCP**. A generic
`mcp-remote` configuration is:

```json
{
  "mcpServers": {
    "contextforge": {
      "command": "npx",
      "args": ["mcp-remote", "https://YOUR-SPACE.hf.space/gradio_api/mcp/",
               "--transport", "streamable-http", "--header",
               "Authorization: Bearer ${CONTEXTFORGE_API_KEY}"],
      "env": {"CONTEXTFORGE_API_KEY": "cf_live_REPLACE_ME"}
    }
  }
}
```

Client formats vary, so prefer its current MCP configuration UI or the snippet
generated by the Space. Never place the key in prompts or Git.

Useful prompts:

- “Use ContextForge to summarize the project memory.”
- “Search ContextForge for decisions about authentication.”
- “Record our SQLite tenancy decision and rationale in ContextForge.”
- “Create a ContextForge work packet for adding a PostgreSQL adapter.”

## Provision a hosted consumer

Mount durable storage at `/data` and configure the Space:

```text
CONTEXTFORGE_STORAGE_MODE=hosted
CONTEXTFORGE_DB=/data/contextforge.db
CONTEXTFORGE_BACKUP_DIR=/data/backups
CONTEXTFORGE_KEY_PEPPER=<secure random value>
```

Generate the pepper with:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

From a trusted administrator environment with access to the same database:

```powershell
python admin.py create-tenant --name "Acme"
python admin.py issue-key --tenant-id "TENANT_UUID"
python admin.py revoke-key --key-id "KEY_ID"
```

The full key is shown once. ContextForge stores only its HMAC digest and tenant
mapping.
